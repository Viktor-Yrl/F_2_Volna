# Volna

[English version](README.md)

Музыкальный проигрыватель для Android на Flutter: папки с музыкой и готовый список радио.

Документация описывает первую версию Volna.

## Возможности

- Четыре вкладки: Top 100, Playlists, Radio и Settings.
- Выбор папок телефона, просмотр треков и обновление без копирования музыки.
- Воспроизведение, пауза, остановка, перемотка, очередь, предыдущий/следующий трек, случайный порядок и повтор.
- Top 100 учитывает 30 секунд прослушивания или половину короткого трека. Радио и скачки перемотки не учитываются.
- Фоновый звук, управление через уведомление и экран блокировки.
- 12 встроенных радиостанций с логотипами; англоязычные идут первыми.
- Английский по умолчанию, русский в настройках; тёмная и светлая Mist Blue темы.
- Сохранение папок, статистики, настроек, очереди и позиции. После запуска звук сам не включается.

Удаление папки из Playlists не удаляет музыку с телефона.
Загрузок, избранного, ручного редактирования плейлистов и добавления радио нет.
Поддерживается Android; iOS не развивается.

## Запуск

Открой `F_5_Implementation/volna` как Flutter-проект.
Проверявшееся окружение: Flutter 3.38.9 / Dart 3.10.8 и Android SDK.

Из корня репозитория:

```powershell
cd F_5_Implementation/volna
flutter pub get
flutter gen-l10n
flutter run
```

Подключи телефон с отладкой по USB или запусти Android-эмулятор.

## Сборка ARM64

Из каталога Flutter-проекта:

```powershell
flutter build apk --release --target-platform android-arm64 --split-per-abi
```

Файл: `build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`.
Сейчас используется ключ разработки, а не производственная подпись.
